# Login Page — HTML & CSS

A simple login page created as a practice project while learning HTML5 and CSS3.

The project focuses on building a basic user interface using semantic HTML and CSS styling, without JavaScript or backend functionality.

## 🚀 Technologies

* HTML5
* CSS3

## 📚 What I Practiced

* HTML document structure
* Semantic HTML elements
* Forms and form inputs
* Text, email, and password inputs
* Radio buttons
* Submit buttons
* CSS Flexbox
* Spacing with `gap`
* Padding and margins
* Borders and border radius
* Background colors
* Linear gradients
* Basic layout and alignment

## 🎯 Purpose

This project was created to practice the fundamentals of frontend development and understand how HTML structures a webpage while CSS controls its visual appearance.

It is one of my first projects while learning web development.
